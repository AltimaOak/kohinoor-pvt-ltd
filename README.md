# Kohinoor Complex Website

A modern and premium commercial website for **Kohinoor Complex**, featuring a futuristic sky-blue themed UI, elegant animations, and a professional business-focused design.

##  Features

* Modern Landing Page
* About Page
* Services Page
* Events Page


##  Pages

### Home

Main showcase page featuring:

* Hero Section
* Services Preview
* Events Preview
* Gallery
* Contact Section

### About

Information about:

* Kohinoor Complex
* Vision & Mission
* Infrastructure
* Commercial Environment

### Services

Showcases the facilities and services provided by the complex.

### Events

Displays:

* Upcoming Events
* Event Gallery

##  Theme

The website uses a premium:

* Sky Blue
* White
* Navy Accent

design system with modern UI/UX principles.
